# Deskhelper Backlog Tecnico

## Fase 0. Fundacao

- criar schema proprio do `deskhelper`
- criar seed tecnico de roles e categorias fixas
- criar admin inicial no dominio `users`
- criar repositorios base de usuarios e tickets
- manter convivencia segura com o dashboard atual

## Fase 1. Acesso

- cadastro publico
- aprovacao de acesso por admin
- login/logout de usuarios do `deskhelper`
- middleware de autenticacao e autorizacao

## Fase 2. Tickets

- abrir ticket
- listar meus tickets
- listar tickets atribuidos ao `operator`
- listar todos os tickets para `admin`
- alterar status
- atribuir responsavel
- historico de eventos

## Fase 3. Operacao

- filtros
- paginacao
- painel admin com totais
- manutencao de categorias fixas
